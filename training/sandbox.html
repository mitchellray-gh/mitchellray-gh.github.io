Ranking sandbox

Type a question, edit the candidate sources, and move the sliders. Everything below is recomputed with real arithmetic: BM25, tf-idf cosine similarity, and a prior.

combined = (BM25 / best BM25) × (0.5 + 0.5 × cosine) × prior

BM25 is divided by the highest BM25 among the sources, so the best keyword match scores 1. Cosine similarity is between 0 and 1, and is blended in as a multiplier between 0.5 and 1, so a perfect direction match keeps the full score and no overlap halves it. The prior is the weight you set per source. If every BM25 is 0, the combined score is 0 for all sources.

Show the arithmetic
f
How many times the query word appears in this source’s text. “sales” appears twice, so f = 2.
k1
How quickly repeats stop helping. 0 means a word counts once however often it appears; higher means repeats keep adding. k1 = 1.2 is a common default.
b
How strongly long sources are penalised. 0 ignores length; 1 scales fully by length. b = 0.75 is a common default.
|d|
Length of this source: its number of words. A 12-word description has |d| = 12.
avg|d|
The average length, in words, over all the sources. Lengths 10, 12 and 14 give avg|d| = 12.
IDF
Rarity of the word: ln(1 + (N − n + 0.5)/(n + 0.5)), where N is the number of sources and n the number containing the word. Rare words weigh more. A word in 1 of 3 sources scores higher than one in all 3.

IDF × (f × (k1 + 1)) / (f + k1 × (1 − b + b × |d| / avg|d|))

The numerator and denominator columns in the tables below are the top and bottom of that fraction, before multiplying by IDF. When the denominator would be 0 the term score is set to 0.
