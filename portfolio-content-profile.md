## 3. Featured Work (Case Studies)

### A) Enterprise BI Design System
- **Problem:** Reporting products across the enterprise BI platform looked and behaved differently. Users had to relearn each dashboard, cognitive load was high, and many users exported to spreadsheets to get work done.
- **Approach:** Led a cross-functional initiative to define a unified UX/UI standard and reusable component library aligned to a broader global design system. Built practical implementation guidance so teams could adopt quickly rather than treat standards as shelfware.
- **Outcome:**
  - **90% faster visual search** (40s -> 4s per task)
  - **~160 hours/year saved** across **500+ users**
  - **99% of users stayed in-tool** instead of exporting to spreadsheets
  - Recognized at a **global UX summit** as the enterprise reporting standard
- **What this demonstrates:** Systems thinking, influence without authority, and measurable usability impact at scale.
- **Tags:** Design system, component library, accessibility, governance, cross-functional leadership

### B) Conversational Data-Discovery Assistant
- **Problem:** Data discovery required a fragmented 5-step journey across catalogs, documentation, and subject-matter experts, slowing onboarding and self-service.
- **Approach:** Designed a plain-English assistant that reduced the journey to **2 clear steps**, with adaptive response patterns for **three personas** (specialist, occasional user, newcomer). Included source grounding, uncertainty handling, and clear next actions.
- **Outcome:**
  - Piloted live with strong testing feedback and adoption interest
  - Reduced time-to-find data from **15–30 minutes to seconds**
  - Established a scalable, governed "front door" for enterprise data discovery
- **What this demonstrates:** Conversational UX, trust pattern design, and practical AI experience design.
- **Tags:** Conversational UX, persona design, adaptive responses, usability testing, governed AI

### C) AI Agent Experience (AIX) Standards
- **Problem:** AI agent interactions were inconsistent with no shared rules around trust, sourcing, and error behavior.
- **Approach:** Defined reusable AI experience standards: citations, confidence cues, follow-up behavior, navigation patterns, uncertainty language, and recovery/error handling. Created a reusable "agent UX kit."
- **Outcome:** Introduced a **UX scorecard** for **findability, trust, cognitive load, and actionability**, giving teams a repeatable quality bar for agent experiences.
- **What this demonstrates:** Product-level governance for AI UX and repeatable quality assurance.
- **Tags:** AI UX standards, trust and citations, UX scorecard, error handling, reusable patterns

## 4.5 Data Engineering Work (Supporting Layer Beneath UX)

> These projects show technical depth behind the UX layer. All terminology remains genericized and safe for public portfolio use.

### DE-1) Enterprise Data Publishing Pipeline
- **Context:** Core product data needed to be made self-service and query-ready for analysts across business units.
- **What I did:** Published platform data into an enterprise lakehouse and downstream reporting layer with governed access patterns.
- **Outcome:** Enabled **1.2M+ downstream views across ~56K users** from governed, reusable data sources.
- **Skills:** Data publishing, lakehouse ingestion, downstream modeling, governed access

### DE-2) Metadata Distillation Pipeline (Signal from Noise)
- **Context:** Too much raw notebook/query content for humans or AI to reason over effectively.
- **What I did:** Built a distillation pipeline to deduplicate, rank assets by real usage, map joins, and extract domain terms.
- **Outcome:**
  - **~600 MB raw notes -> ~230 KB distilled context** (~2,600x reduction)
  - Removed **860+ duplicates**
  - Produced structured context: **~5,900 tables, ~4,400 join keys, ~350 validated query patterns, 80+ domain terms**
  - Improved grounding quality for conversational discovery workflows
- **Skills:** Deduplication, metadata extraction, context engineering, knowledge distillation

### DE-3) Cloud Storage Architecture for Large Attachments
- **Context:** Large binaries stored in relational/lakehouse layers were causing cost and performance drag.
- **What I did:** Re-architected storage to move large files into cloud object storage, exposing lightweight references in analytics views.
- **Outcome:** Lower compute/storage overhead and cleaner in-report file access patterns.
- **Skills:** Storage architecture, cost optimization, data modeling, systems integration

### DE-4) AI-Powered SQL Assistant (Backend UX Engineering)
- **Context:** Analysts were losing time finding valid tables and reconstructing syntax.
- **What I did:** Built a lightweight app with SSO-aware access control, real-time catalog lookup, and ingestion of **2,800+ query patterns** to ground SQL generation.
- **Outcome:** Reliable SQL assistance using real table/column context and governed access boundaries, reducing hallucinated outputs.
- **Skills:** API integration, OAuth/SSO, RAG grounding, semantic query layer, rapid prototyping

### DE-5) Data Catalog and Metadata Governance
- **Context:** Data trust and discoverability were hindered by incomplete metadata and unclear ownership.
- **What I did:** Led metadata curation and completeness scoring dimensions across table-level governance fields.
- **Outcome:** Better discoverability, better trust signals, and measurable governance baselines.
- **Skills:** Metadata management, governance frameworks, stewardship, cataloging

### DE-6) Data Quality Standard and Scoring
- **Context:** No shared enterprise definition of high-quality data.
- **What I did:** Contributed to quality dimensions, thresholds, and scoring models using canonical structures and reporting patterns.
- **Outcome:** Repeatable, comparable data quality measurement with a consistent visual standard.
- **Skills:** Data quality frameworks, canonical modeling, governance architecture

### DE-7) Capacity Consolidation and Cost Optimization
- **Context:** Redundant analytics workspaces increased cost and reduced maintainability.
- **What I did:** Performed usage analysis and consolidation recommendations to remove duplication and right-size capacity.
- **Outcome:** Reduced redundant infrastructure and estimated annual cost avoidance.
- **Skills:** Platform analysis, capacity planning, optimization

### DE-8) Dimensional Modeling and SQL Enablement
- **Context:** Analysts needed faster onboarding to enterprise data structures.
- **What I did:** Designed and taught practical modeling patterns (fact/dimension, PK/FK, cardinality, bronze/silver/gold architecture) with governed SQL examples.
- **Outcome:** Faster onboarding and stronger self-service adoption.
- **Skills:** Dimensional modeling, medallion architecture, SQL enablement, technical training
